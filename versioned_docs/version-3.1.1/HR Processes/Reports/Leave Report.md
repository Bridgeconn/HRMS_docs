The **Leave Report** feature in HRMS allows HR users to view and generate detailed reports of employee leave records. It helps in tracking leave requests, analyzing patterns, and exporting data for reporting or audit purposes.

HR users can generate different types of reports, including:

- **Leave Report**
- **Leave Balance Report**
- **Leave History**
- **Monthly Leave Report**

These reports provide a comprehensive view of employee leave data across multiple perspectives.

## Accessing Leave Report

1. Log in to the **HRMS Dashboard**
2. Navigate to **Reports**
3. Click on **Leave Reports**
4. Select **Leave Report**
5. Click on **Open Report View**

## Leave Report Filter

The **Leave Report Filter** screen allows you to define criteria for generating reports.

### Available Filters

- **Department**
  - Select a specific department from the dropdown
  - Helps narrow down results to a particular team

- **Start Date**
  - Choose the beginning date for the report

- **End Date**
  - Choose the ending date for the report

- **Employee Selection**
  - Displays a list of employees with:
    - Employee ID  
    - Employee Name  
  - Select employees using checkboxes

- **Select All / Deselect All**
  - Quickly select or clear all employees

## Generating the Report

1. Apply the required filters:
   - Department (optional)
   - Start Date and End Date
   - Employee selection
2. Click on **Generate Report**

Reports are automatically generated and sent to the HR user's registered email address in **Excel format**.
