The **Attendance Report Summary** provides a comprehensive view of employee attendance data across multiple levels, including individual, all employees, and department-wise reports. This feature enables HR to monitor attendance patterns, analyze workforce trends, and make informed decisions. 

**Who Can Access?** 

Available to HR users and authorized roles 

**How to Access Attendance Reports** 

- Log in to the system using your HR profile  

- Navigate to the Reports tab  

- Click on Attendance Reports  

-Select the required report type:  

    - Attendance History – View complete attendance logs  

    - Monthly Attendance Report – Track daily attendance for a selected month  

    - Attendance Summary – Get an overview of working days, WFH, and leave counts 

**Generating Attendance History Report** 

- Click on Attendance History  

- In the filter window:  

- Select Department  

- Choose Start Date and End Date  

- Select employees (or use Select All / Deselect All)  

- Click Generate Report 

The report is generated in Excel format and sent to the HR user’s registered email.
